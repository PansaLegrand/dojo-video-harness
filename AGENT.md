# Coding agent entry point

Read [AGENTS.md](AGENTS.md) before working in this repository. It is the canonical
guide to architecture, commands, editing invariants, managed UI and verification.

SDK changes belong in [Dojo Video Engine](https://github.com/PansaLegrand/dojo-video-engine).

Keep repository instructions in `AGENTS.md`; this entry point intentionally does
not duplicate them.
