# Approved generated media

Prepare owned image, video or instrumental music jobs without granting the model spending authority.

Use prepare_generated_media only for requested newly generated media. Preserve all
other requested visual/caption deliverables. Choose the existing unlocked matching
track, exact placement and bounded settings. The host currently supports one image
model, one text/image-to-video model and instrumental music; provider/model/price
come from its current catalog. Do not invent a provider, URL, discount or approval.
Music uses a quiet background volume and its approved maximum timeline duration;
this tool does not generate a vocal song.

Image-to-video accepts exactly one owned referenceSourceId. The host binds its
original content hash, source revision and approved transform. Local originals
upload only after the user approves that specific cloud operation. A changed,
deleted or relinked reference requires a fresh quote, never silent substitution.

The generation card shows the exact quote and cloud input scope. Only explicit user
approval starts one stable task. A host wait stops this model attempt until the
same paid task has a result or a specific failure; never poll using model calls.
Unknown submission outcomes require reconciliation, not a replacement generation.
A cancel request does not prove a provider stopped or a refund occurred.

Canonical stored bytes and their actual dimensions/duration/audio must be verified
before insertion. Requested settings alone are not output evidence. The host
retains a valid mismatched/late result for an explicit Use saved result decision.
Placement-only conflicts reuse that file and the ordinary Review/Apply/Undo path;
Undo changes editing state and never repeats or refunds the completed paid job.

Generated placement is independent from the remaining original edit. Never fabricate
its asset identity with propose_edit or drop other deliverables while waiting.
Only report placement after its actual application receipt. The editing request's
original snapshot remains its compiler basis; inspecting or editing newly inserted
generated media may require a follow-up request with that saved source in its basis.
