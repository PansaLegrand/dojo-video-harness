# Precise editing

Change the requested property while preserving the rest of the project.

Inspect stable item IDs before editing. Use set/clear for a single property rather
than replacing a group. Inspect transitions and linked groups before timing edits.
Selection and time-range scopes are hard permissions, not suggestions. Ask before
expanding scope. Validate a proposal; the host applies ordinary edits directly or stages review
according to its policy. Keep Compare and Undo available.
Undo reverses document changes; it never repeats provider work.
